# SwDailyNotes Fields

Manual developer-site setup reference for the first `switchboard-core` test path.

## Required

- `Title` Single line of text
- `SwLogDate` Date only
- `SwEventTime` Date and time
- `SwEntryType` Choice
- `SwTitle` Single line of text
- `SwSummary` Multiple lines text
- `SwDetails` Multiple lines text
- `SwSourceModule` Single line of text
- `SwSourceItemId` Single line of text
- `SwSearchText` Multiple lines text
- `SwLocationText` Single line of text
- `SwCategoryText` Single line of text
- `SwOperatorName` Single line of text

## Optional

- `SwShift` Choice
- `SwIsPrinted` Yes/No
