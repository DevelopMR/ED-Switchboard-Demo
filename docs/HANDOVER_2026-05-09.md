## Project Summary

This repository is building a modular SharePoint Online / SPFx proof of concept for an Emergency Department switchboard operator console.

Current primary focus:

- `switchboard-core-spfx`
- shell header below the purple header band
- three-column operator layout
- search-friendly Daily Notes center experience
- shell-owned popup host for urgent workflows
- SharePoint adapter wiring for `SwDailyNotes` and `SwShellState`

## Current High-Level Architecture

Implemented direction:

- `switchboard-core` owns shell layout, Daily Notes, module column, popup host, and shell safety behavior
- right-column workflows will eventually write into `SwDailyNotes`
- `SwDailyNotes` is the main search-friendly list
- `SwShellState` is the lightweight shell metadata list for drawer-count JSON persistence
- popup host is owned by the shell, not by individual modules
