# SharePoint List Seed Data

Store safe demo seed files here for lists such as:

- `SwDailyNotes`
- `RmDemoEntries`
- `PgOverheadPageLog`
- `CodeAlerts`
- `CaActionLogs`
- `CodeAlertEndpoints`
- `OrCallIns`
- `OrCallInContacts`
- `DuiIntakes`
- `PagingLogs`
- `AlarmPanelLogs`

The obsolete `CaAlertRules` seed inventory was removed in package `0.1.20`; released switchboard workflows are app-owned.

`CodeAlerts`, `CaActionLogs`, and `CodeAlertEndpoints` remain future Originator/intake artifacts.
