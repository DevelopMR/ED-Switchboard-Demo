# Test Data Workspace

All content in this folder must remain synthetic and safe for demonstration use.

Use this folder for:

- Seed data for SharePoint demo lists
- Scenario scripts for end-to-end walkthroughs
- Safe fake names, departments, phone numbers, and alert examples

Current Code Alert backend verification uses only internal demo rows in `RmDemoEntries`, `PgOverheadPageLog`, and `SwDailyNotes`. Never copy real list exports or screenshots containing sensitive information into seed files.
